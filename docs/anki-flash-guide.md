# Anki 学习功能 · 刷机与使用说明

本分支在 **kiikoread 官方 rc102** 基础上移植了 Anki 卡组学习功能，版本号 **0.3.3-rc102.01**。

固件文件：固件随仓库提供 —— [`firmware/Read_Pico-0.3.3-rc102.01.bin`](../firmware/Read_Pico-0.3.3-rc102.01.bin)（3.3 MB，**当前可用来源**，只烧应用分区 0x10000）。若本仓库的 **Releases** 页面发布了对应版本，优先使用 Release 附件（含版本说明）；需要回滚时使用 [`firmware/Read_Pico-0.3.3-rc100.02.bin`](../firmware/Read_Pico-0.3.3-rc100.02.bin)。

---

## 一、刷机步骤

> 顺序不能颠倒：先保存配置 → 用官方 **rc102** 把设备恢复到干净基线 → 覆盖应用分区 → 恢复出厂 → （可选）还原配置。

### 第 0 步（前提）：先保存配置

第 3 步的「恢复出厂设置」会清空设备设置项，**刷机前请先保存一份配置备份**：

1. 把 TF 卡插到设备；
2. 进入 **设置 → 维护 → 保存与恢复配置**；
3. 点按 **「保存当前配置到 TF 卡」**，出现成功提示即可。

备份内容包含**阅读记录、设备资料、书签与已保存的 WiFi**（书籍、字体、图片仍需留在 TF 卡上）。

> ⚠️ 备份文件含 WiFi 密码，请妥善保管 TF 卡。
> 刷完第 3 步（恢复出厂）后，用同一页面的 **「从 TF 卡恢复配置」** 即可把设置、阅读记录和书签还原回来。

### 第 1 步：线刷官方（厂长）固件 **rc102**

用 USB 线把设备接到电脑，按官方 rc102 的刷机方式完整刷入一次：

- 官方发布页：<https://github.com/wegooo-cell/read-pico-reader/releases/tag/v0.3.3-rc102>
- 完整刷入（含 bootloader / 分区表 / otadata），确保设备停在 **rc102** 基线
- 刷完在设备「设置 → 当前版本」确认显示 `0.3.3-rc102`

> 基线选 rc102 是因为本应用就是用 rc102 源码编的（版本号 `0.3.3-rc102.01`），基线与应用同源。
> **若手上只有 rc100 也可直接使用**：rc100→rc102 的 Pico 分区表与引导布局逐行相同，本固件只写 `0x10000` 应用分区，不影响引导与分区。

### 第 2 步：用 Flash Download Tool 覆盖应用分区

打开乐鑫 **Flash Download Tool**（Espressif Flash Download Tool）：

1. ChipType 选择 **ESP32-S3**，WorkMode 选择 **Develop**，加载模式选默认；
2. 在下载列表第一行选择本仓库的 `Read_Pico-0.3.3-rc102.01.bin`，**地址填 `0x10000`**；
3. 波特率建议 `921600`（不稳就降到 `460800`），选择设备串口后点击 **START**；
4. 等待 `FINISH`，设备会自动重启。

习惯命令行的用户等价操作：

```bash
python -m esptool --chip esp32s3 -p COM3 -b 460800 \
  write_flash --flash_mode dio --flash_freq 80m --flash_size 16MB \
  0x10000 Read_Pico-0.3.3-rc102.01.bin
```

> ⚠️ 只写 `0x10000` 这一个地址，不要动 bootloader（0x0）、分区表（0x8000）、otadata（0xd10000）。
> 若刷完「当前版本」没变化，说明有其他启动槽在生效：重新执行第 1 步的完整线刷，再把本 bin 写到 `0x10000`。

### 第 3 步：恢复出厂设置

进入设备 **设置 → 维护 → 恢复出厂设置**，执行一次。这会清掉旧版本残留的设置与缓存，确保新界面（首页 Anki 入口、字体、排版参数）按默认值生效。

> 恢复出厂只清设置项（NVS），**不会删除 TF 卡上的文件，也不会删除内置存储里的书籍与卡组**。
> 如果第 0 步做过配置备份，此时可进入 **设置 → 维护 → 保存与恢复配置 → 「从 TF 卡恢复配置」**，把阅读记录、书签与 WiFi 还原。
> 若担心设置里残留旧版参数影响新功能，也可以先不还原，确认 Anki 功能正常后再恢复配置。

### 第 4 步：准备题库

把 `.apkg` 文件放到 **TF 卡根目录下的 `anki` 文件夹**（即 `/anki/`，导入界面也会扫描 TF 卡根目录）。

```text
TF 卡根/
└── anki/
    └── 你的题库.apkg
```

## 二、使用流程

1. 开机后首页顶栏有 **「Anki 学习」** 按钮，点按直达；也可以在**文件管理**里直接点 `.apkg` 文件导入。
2. 导入完成后卡组列表出现你的卡组（空卡组不显示），点卡组进入学习。
3. **正面**：`【单选】/【多选】` 题型 + 题干 + `A.` `B.` `C.` `D.` 选项。
4. **轻点翻面**进入背面：正确选项为正常黑字（清晰可读），**错误选项整行反色**，「答案：AC」一行给出正确答案。
5. 上下滑翻页（长题干/长选项折行后自动分页），四个按钮评分：忘记 / 困难 / 良好 / 简单；进度实时写回卡组文件。

### 数据存放位置

| 场景 | 卡组与媒体位置 |
| --- | --- |
| TF 卡在位 | `/sdcard/anki/`（优先，节省内置存储） |
| TF 卡不在位 | `/flash/anki/`（内置存储） |

拔卡时学习会话不会中断；回到列表后只显示可访问的卡组。

## 三、已知限制（本版本）

- **题目插图暂不显示**：本版尚未实现 `.apkg` 媒体（图片）渲染，题目里的图会以占位文本出现（计划在后续版本支持）。
- 0 张卡的卡组不在列表显示（例如导入后留下的空 `Default`）。
- 界面语言与字体跟随系统设置；正文字号过大时会自动降号以避免单卡超过 3 页。
