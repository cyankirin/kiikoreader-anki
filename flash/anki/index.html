KIIKOREAD · ANKI FORK

kiikoread · Anki 学习固件。

这是本 fork（kiikoread · Anki）的 Anki 版固件网页刷机入口：在设备上导入 .apkg，按 Anki 调度复习。 刷机会写入引导程序（0x0）、分区表（0x8000）、应用（0x10000）与启动槽标记（0xd10000）；擦除是可选的，默认不勾选。

This fork adds Anki deck study on top of kiikoread. Flashing writes the bootloader, partition table, app and slot marker; erasing is an optional step whose checkbox is left unchecked, so your data stays.

旧版本使用仓库当前的引导程序与分区表（各版本分区表一致，仅应用镜像不同），刷完仍可再选回最新版。

用数据线连接墨水屏，然后点击下面的按钮。
点下去后，本页会先把四个部件各下载一次并逐个核对 SHA-256，四项全部与清单一致才打开串口写入； 任何一项不一致都会立即中止，设备内容不受影响。

写入前还会出现一步「Erase device」询问：保持不勾选再点「Next」，设置与阅读进度就会保留； 勾选它才是整片擦除（本页不会替你勾上）。

当前浏览器不支持 WebSerial：请改用电脑上的 Chrome 或 Edge，并通过 HTTPS 打开本页。 本页需要 HTTPS：请用 https 地址打开，或先运行本机的本地静态服务。

刷机前请确认

  • 连接后会出现一步「Erase device」询问：保持不勾选再点「Next」，设置与阅读进度都保留；勾选会整片擦除。
  • 使用电脑上的 Chrome 或 Edge（版本 89 及以上），并通过 HTTPS 或 localhost 打开本页。
  • 数据线要能传数据；刷机过程中不要拔线、不要让电脑休眠。
  • 连接后列表里找不到设备时，先在墨水屏上进入 「设置 → 升级和恢复 → BOOT 刷机」，再重新点上面的按钮。
  • 同时打开串口工具会占用端口，请先关闭再刷机。

刷完之后

  • 设备会自动重启到新的 Anki 版固件；只要没有勾选「Erase device」，原有设置与阅读进度都还在。
  • 把 .apkg 放到 TF 卡的 /anki/ 目录，在文件页直接打开即可开始复习。
  • 需要回到原版固件：在「设置 → 升级和恢复」恢复出厂设置，或刷回官方完整包。
  • 详细步骤见 中文刷机说明 ↗。
kiikoread · Anki fork · 第三方阅读固件，非官方发布。 刷机包由本仓库的构建产物现场生成：发布前由 CI 逐项校验大小与 SHA-256（tools/verify_flash_bundle.py）， 刷机时本页按 manifest.json 再逐个核对一遍，两次都通过才会写入设备。 这一步挡的是传输损坏、缓存里的旧文件与半截下载；清单与固件本身仍由本仓库发布，请确认你打开的是这个站点。
